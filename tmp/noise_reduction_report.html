2. Hyperparameter Settings

Below are the parameter settings applied in sizing.py:

Sizing parameters (optimized via tmp/optimize_sizing_improved.py)


SUPERSMOOTHER_PERIOD_ENTRY = 8       # Faster entry smoothing to capture trends early


SUPERSMOOTHER_PERIOD_EXIT = 4        # Responsive exit smoothing


SCORE_ENTRY = 0.435160              # Balanced entry threshold


SCORE_EXIT = 0.294856               # Balanced exit threshold


CB_ACTIVATE = -3.386067             # Deep circuit breaker activation (prevents locking out in runs)


CB_COOLOFF = 0.789564               # Circuit breaker reset threshold


COMP_ENTRY_BOOST = 2.000613         # Deep value accumulation entry override


USE_BEAR_OVERRIDE = False           # Disabled to prevent whipsaws from single-day regime shifts


RCO_DAYS = 3                        # 3-day Re-entry Cool-off (prevents quick churn)


MHP_DAYS = 12                       # 12-day Minimum Holding Period (forces trend riding)

Key Architectural Discovery: Disabling USE_BEAR_OVERRIDE

Previously, when the HMM regime was classified as BEAR for even a single day, it immediately forced exposure to 0.0. This bypassed all smoothing and holding periods, causing multiple noise trades and premature exits during short-term pulldowns (e.g., 2019-04-09, 2020-02-16, and 2020-05-23).

By disabling USE_BEAR_OVERRIDE and relying purely on the Ehlers SuperSmoother over the ensemble final_score (which already factors in the HMM probabilities) alongside a 12-day Minimum Holding Period (MHP), the system is protected from high-frequency HMM regime shifts. The strategy now rides trends cleanly while remaining out during macro bear years.
